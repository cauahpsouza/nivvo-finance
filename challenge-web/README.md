# Desafio Nivvo

Aplicação pública, mobile-first e independente do Nivvo local. Toda a partida acontece no navegador e o progresso individual fica em `localStorage`.

## Executar

```bash
npm install
npm run dev
```

Abra a URL local informada pelo terminal.

## Validar

```bash
npm run lint
npm test
npm run build
npm run start
```

O app não exige variáveis de ambiente, backend, banco ou conexão com o Nivvo principal. Para publicar na Vercel, selecione `challenge-web` como **Root Directory**.
